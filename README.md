# Jonathan Jacob Koshy Portfolio

Personal portfolio for firmware, embedded systems, robotics, edge-computing, and GPU systems work.

## Stack

- React
- Vite
- Tailwind CSS
- React Router
- Lucide icons

## Local Development

Use Node.js 22.12.0 or newer. The preferred version is in `.nvmrc` (`nvm use` if you have nvm installed).

```bash
npm ci
npm run dev
```

Open this folder in VS Code to use the project settings and install the recommended ESLint and Tailwind CSS extensions. Run **Debug portfolio in Chrome** from Run and Debug to start Vite and open the site with source debugging. The **dev**, **lint**, and **build** tasks are also available from **Tasks: Run Task**.

## Validation

```bash
npm run lint
npm run build
```

## Content

Portfolio content is centralized in `src/data/portfolio.js`.
