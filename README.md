# Jonathan Koshy Portfolio

Personal portfolio for firmware, embedded systems, robotics, edge-computing, and GPU systems work.

## Stack

- React
- Vite
- Tailwind CSS
- React Router
- Lucide icons

## Local Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Content

Portfolio content is centralized in `src/data/portfolio.js`.
